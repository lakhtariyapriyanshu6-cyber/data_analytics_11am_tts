A **database** is an organized collection of data stored electronically so it can be easily accessed, managed, and updated.

Examples:
- A school database stores student names, grades, and attendance.
- A banking database stores customer accounts and transactions.
- An online store database stores products, customers, and orders.

A **DBMS** (Database Management System) such as MySQL, PostgreSQL, or MongoDB is software used to interact with a database.

'''
   ## Types of Databases

1. **Relational database**  
   Stores data in tables with rows and columns.  
   Examples: MySQL, PostgreSQL, Oracle, SQL Server.

2. **NoSQL database**  
   Stores flexible, non-tabular data such as documents or key-value pairs.  
   Examples: MongoDB, Redis, Cassandra.

3. **Hierarchical database**  
   Organizes data in a tree structure with parent-child relationships.

4. **Network database**  
   Allows records to have multiple relationships with one another.

5. **Object-oriented database**  
   Stores data as objects, similar to object-oriented programming.

6. **Distributed database**  
   Stores data across multiple computers or locations.

7. **Cloud database**  
   Hosted and accessed through cloud services.  
   Examples: Amazon DynamoDB, Google Cloud Spanner.
